## Project Overview

This repository documents the design, development, implementation, and evaluation of a Call Data Record (CDR) Analysis and Link Analysis System as part of the MIT 8103 practical database portfolio.

The project uses synthetic telecommunications call records to demonstrate database modelling, data management, SQL query processing, performance optimisation, transaction management, concurrency control, NoSQL concepts, and distributed database principles.

## Project Objectives

The system is intended to:

1. Import and validate synthetic call records from CSV files.
2. Store and retrieve call-event information using PostgreSQL.
3. Analyse incoming and outgoing calls, communication frequencies, and call durations.
4. Identify direct communication relationships between telephone-number identifiers.
5. Demonstrate advanced database operations and performance evaluation.
6. Explore NoSQL and distributed database approaches using the same case study.

## Dataset and Ethical Considerations

The project will use an initial dataset of 2,000 entirely synthetic call records.

No real subscriber information, live telecommunications data, or intercepted communications will be used.

The system is intended solely for academic demonstration.
